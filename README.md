# Locate Everything

An open-vocabulary visual object localization test application built with Streamlit and vision-language models.

## Features
- **Prompt-Based Detection**: Detect and localize objects in arbitrary images using open-ended natural language descriptions.
- **Streamlit Interactive UI**: Upload images, type target queries, and visualize bounding boxes with confidence scores.
- **Client Integration**: Seamless communication with local Llama/VLM inference servers.

## Quick Start
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```
